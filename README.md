# customer_behaviour_Analysis
This project analyzes 3,900 customer transactions to understand shopping patterns, customer segments, product preferences, and subscription behavior. The goal is to turn raw transactional data into meaningful business insights that can support strategic decision-making.

I performed Exploratory Data Analysis (EDA) using Python (Pandas) for data cleaning, missing value imputation, feature engineering, and data preprocessing. Further structured business analysis was conducted using MySQL, and an interactive dashboard was built in Power BI to visualize key insights.
